# Consignes de l'utilisateur (données le 28/09/2026)

- Ne fais jamais le travail toi-même.
- Délègue toujours à des sub-agents.
- N'utilise pas constamment Opus : Opus seulement pour les tâches complexes, sinon privilégie Sonnet.
- S'il reste des zones d'ombre ou des points pas assez clairs, pose les questions et attends les réponses.

## Routage des modèles
- Code simple, résumés -> Sonnet
- Architecture, refacto -> Opus
- Contexte minimal pour chaque sub-agent
- Résume chaque résultat en 3 lignes

## Vérification
- Relis toujours le code et valide son bon fonctionnement
- Vérifie qu'il n'y ait pas de code mort
- Mets toujours à jour toutes les documentations
- Fais des tests fonctionnels
- Fais des vérifications de sécurité
